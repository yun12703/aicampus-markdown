# 제목테스트

지금부터 마크 다운의 문법을 하나씩 소개.

# 헤드라인(제목)
문서에서 부분 별로 부여하는 제목을 나타내기 위한 문법입니다.
줄 맨 앞에 (백틱'')을 이용해서 혹은 맨 앞에 #을 1개부터 6개까지 붙이고
띄어쓰기를 한 뒤에 내용을 적어 표시할 수 있습니다
"""
# 제목1
## 제목2
### 제목3
#### 제목4
##### 제목5
###### 제목6
"""

> tip 
>
> 제목 4부터는 일반글자와 크기가 비슷하거나 작아지므로 사용에 주의하세요

# 글자 강조 효과
문서를 작성할 때 원하는 부분을 강조하는 효과를 줄 수 있습니다.
문법은 다음과 같습니다.

'''
**굵은글씨**
*기울임글씨*
***굵고 기울인 글씨***
~~취소선~~
'인라인 블럭'
'''

사용 예시는 다음과 같습니다.

나는 오늘 저녁에 **치즈**가 듬뿍 들어간 ***피자***를 먹을테다!
~~텅장주의~~

# 목록(LIST)

목록은 동일한 내용 또는 순서대로 진행해야 하는 내용들을 나열할 때 사용하는 방식입니다.

예를 들어 프로그래밍 언어의 종류는 다음과 같습니다.

- C/C++
- Jaba
- Python
- Javascript
- Go

우리가 배우는 파이썬 순서를 목록으로 나타내 보면 다음과 같습니다.

1. 파이썬 공통과정
2. Numpy
3. OpenCV
4. Tkinter
5. Pandas
6. ML
7. DL
8. Linux

목록을 응용해서 체크리스트를 만들 수도 있습니다.(띄어쓰기 주의)
[ ] - <input checkbox>

### 매일 해야할 일
- [x] 밥 잘 먹기
- [ ] 복습 1시간 이상 하기
- [ ] 30분 이상 걷기
- [x] 잠 5시간 이상 자기

    - 리스트
    - 라이브러리
