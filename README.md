# 제목테스트

지금부터 마크 다운의 문법을 하나씩 소개.

# 헤드라인(제목)
문서에서 부분 별로 부여하는 제목을 나타내기 위한 문법입니다.
줄 맨 앞에 (백틱'')을 이용해서 혹은 맨 앞에 #을 1개부터 6개까지 붙이고
띄어쓰기를 한 뒤에 내용을 적어 표시할 수 있습니다
"""
# 제목1
## 제목2
### 제목3
#### 제목4
##### 제목5
###### 제목6
"""

> tip 
>
> 제목 4부터는 일반글자와 크기가 비슷하거나 작아지므로 사용에 주의하세요

# 글자 강조 효과
문서를 작성할 때 원하는 부분을 강조하는 효과를 줄 수 있습니다.
문법은 다음과 같습니다.

'''
**굵은글씨**
*기울임글씨*
***굵고 기울인 글씨***
~~취소선~~
'인라인 블럭'
'''

사용 예시는 다음과 같습니다.

나는 오늘 저녁에 **치즈**가 듬뿍 들어간 ***피자***를 먹을테다!
~~텅장주의~~

# 목록(LIST)

목록은 동일한 내용 또는 순서대로 진행해야 하는 내용들을 나열할 때 사용하는 방식입니다.

예를 들어 프로그래밍 언어의 종류는 다음과 같습니다.

- C/C++
- Jaba
- Python
- Javascript
- Go

우리가 배우는 파이썬 순서를 목록으로 나타내 보면 다음과 같습니다.

1. 파이썬 공통과정
2. Numpy
3. OpenCV
4. Tkinter
5. Pandas
6. ML
7. DL
8. Linux

목록을 응용해서 체크리스트를 만들 수도 있습니다.(띄어쓰기 주의)
[ ] - <input checkbox>

### 매일 해야할 일
- [x] 밥 잘 먹기
- [ ] 복습 1시간 이상 하기
- [ ] 30분 이상 걷기
- [x] 잠 5시간 이상 자기

목록은 중첩도 가능합니다. 단, 들여쓰기를 잘 해야합니다 (탭키 사용 권장)

1. 파이썬 기초
    - 변수와 사칙연산
    - 입출력
    - 조건과 반복
    - 리스트
    - 라이브러리
2. Numpy
    - ndarray
    - 불리언 인덱싱
    - 축 지정 명령들
    - 형태 변경

# 링크(Link)

링크는 클릭하면 다른 페이지로 이동 가능한 연결 도구를 말한다.

다음과 같은 문법을 사용합니다.

'''
[보여줄 글자](연결할 주소)
'''

표시 예시는 다음과 같습니다.
- [파이썬 홈페이지](https://www.python.org/)
- [https://www.python.org/](https://www.python.org/)
- <https://www.python.org/>

같은 저장소의 문서는 '상대경로'를 이용해서 접근할 수 있습니다.

# 표(table)
표는 줄과 칸을 만들어서 데이터를 배치하기 위한 도구
대부분의 markdown에서 가능하지만 discord에선 안됨

'|'를 칸막이로 쓰고, '-'를 칸으로 쓴다. '-'는 최소 3개 이상 써야함

|번호|이름|속성|
|---|---|---|
|1|이상해씨|풀|
|3|피카츄|전기|
|4|파이리|불꽃|
|25|꼬부기|물|

정렬 상태까지는 마크 다운에서 문법을 통해 조정이 가능함.
